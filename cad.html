Prototype controls: Ctrl+N/O/S = new/open/save · drawings recover automatically after refresh · select an object, then click a white grip to edit it · L = line · PL = polyline · REC = rectangle · C = circle; choose 2P/3P before the first point or D after the center · A = three-point arc · M = move · CO = copy · RO = rotate · SC = uniform scale · type R after the RO/SC base point for reference mode · O = offset · TR = trim · EX = extend · use the Layers panel to create, rename, color, hide, lock, assign, and safely delete layers · Enter/right-click/Esc finishes or cancels the current edit · F8 = ortho · Ctrl+Z/Y = undo/redo
